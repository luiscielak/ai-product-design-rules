# Design Ops Cockpit

A single-user web app where a designer intakes a product brief, launches a design run, and steps through six pipeline stages — new project, PRD, lo-fi, mid-fi, UI prototype, hi-fi — reviewing each generated artifact and choosing **approve** or **request revision** before the next stage starts.

Generated by `/new-project` from the AI Product Design Rules.

| Field | Value |
| --- | --- |
| `project_name` | `design-ops-cockpit` |
| `project_type` | `ai-product-design` |
| `include_marketing` | `true` |
| `design_system` | **`konstrukt`** (v2.0.0) |

Later stages (`/prd`, `/lofi`, `/midfi`, `/ui-proto`, `/hifi`) inherit `design_system: konstrukt` from this file.

## Design system

Konstrukt v2.0.0 — [the-hooman-loop/konstrukt](https://github.com/the-hooman-loop/konstrukt) (MIT).

- Swiss / Bauhaus: `--radius: 0px`, `--shadow: none`, no gradients
- One palette (`atelier`); light / dark via `data-mode` on `<html>`
- Tokens come from generated build output only. Vendored at `vendor/konstrukt-2.0.0/` (`konstrukt.css`, `base.css`, `theme.js`, `tokens.json`). **Do not hand-type hex.**

## Setup

Prototype (the runnable app):

```bash
cd app
npm install
npm run dev
```

Open the URL printed by Next.js (usually `http://localhost:3000`).

## Folder structure

```
projects/design-ops-cockpit/
├── app/                         # Next.js prototype (/ui-proto)
├── docs/
│   ├── PRD.md                   # /prd
│   └── presentations/
├── design/
│   ├── wireframes/lofi/         # /lofi
│   ├── wireframes/midfi/        # /midfi + ui.html
│   └── ui-design/               # /hifi
├── vendor/konstrukt-2.0.0/      # canonical Konstrukt v2.0.0 dist/
└── marketing/                   # waitlist stub
```

## Pipeline

1. `/new-project` — this tree
2. `/prd` — `docs/PRD.md`
3. `/lofi` — `design/wireframes/lofi/`
4. `/midfi` — `design/wireframes/midfi/`
5. `/ui-proto` — `app/`
6. `/hifi` — `design/ui-design/`

## Assumptions recorded at bootstrap

- Single operator (Luis). No auth, teams, or multi-run collaboration in MVP.
- Artifacts are files written by an AI agent that follows this rules repo.
- Marketing is a static waitlist page, not a second Next.js app (see RUN-NOTES).
