# Finley

Sample product for the AI product design pipeline: a personal finance dashboard for a solo consultant.

The coded prototype lives in [`app/`](app/). All figures are invented sample data.

```bash
cd app
python3 -m http.server 4173
```

Then open http://localhost:4173. See [`app/README-proto.md`](app/README-proto.md) for screens, interactions, and gaps.
